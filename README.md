## 🎮 Overview

**Java Snake Game** is a classic retro-style game built using **Java Swing**.  
Control your snake, collect apples, and avoid hitting walls or yourself!  
With smooth controls, pixel-style graphics, and real-time gameplay, this project revives the nostalgic charm of old-school gaming while showcasing essential Java GUI and event-handling concepts.

---

## ✨ Features

- 🕹️ Smooth keyboard controls  
- 🍎 Apple collection & score tracking  
- 🧱 Collision detection with self and walls  
- 🐍 Dynamic snake growth  
- 💻 Built entirely in **Java Swing** (no external libraries)  
- 🎨 Simple yet engaging pixel graphics  

---

## 🧠 Learning Highlights

This project helps you understand:
- Java **OOP concepts**
- **Swing GUI** components
- **Timer-based animation** and game loops  
- **Keyboard event handling**
- Real-time rendering and repaint logic
